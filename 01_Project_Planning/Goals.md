# Project Goals

## Project Title

Low-Cost Torque Estimation and Impedance-Control Testbed for Wearable Hip-Robot Actuators


## Motivation

Wearable robots require accurate actuator torque control to provide safe and effective human assistance.

Commercial wearable robots often use expensive torque sensors. This project investigates whether low-cost sensors and actuator models can estimate torque accurately enough for wearable robotics applications.


## Main Objective

Design and develop a low-cost robotic actuator testbed capable of:

- Measuring motor position and current.
- Estimating actuator torque.
- Controlling desired torque.
- Demonstrating impedance control behavior.


## Research Questions

1. Can motor current and position information estimate actuator torque?

2. How accurate is the estimated torque compared with a load-cell measurement?

3. Can a low-cost actuator achieve closed-loop torque control?

4. Can impedance behavior be demonstrated using inexpensive hardware?


## Expected Contribution

This project will create a research platform for studying:

- Low-cost torque estimation.
- Embedded motor control.
- Actuator validation.
- Impedance control for wearable robotics.


## Final Demonstration

The completed system should demonstrate:

- A working robotic actuator.
- Sensor feedback system.
- STM32-based controller.
- Torque estimation algorithm.
- Closed-loop torque control.
- Impedance control experiment.
